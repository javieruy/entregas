Where to start

  1. Open the building guide first (the file 00-building-guide.pdf): in 4 pages, it shows how to cut out, fold and glue the pieces.
  2. Print at actual size (100%), never “fit to page”: otherwise the sheets and the base won't line up.
  3. Pick thick paper (cardstock, 160 g/m² or about 60 lb) or glue the sheets onto a cereal box before cutting: they stand up much better.
  4. Start with The Starry Night: it's the easiest, and the only one with a standing cypress that slides together into a cross.
  5. Color with the color key on the first page, cut along the drawing, fold the base and glue on sheets A, B and C.
